# AGENT SERVICE (AGENTIC AI LAYER)

## PURPOSE

The Agent Service is the intelligence layer of the platform.

Instead of sending user queries directly to a recommendation engine, the system uses multiple AI agents that collaborate to understand the request, gather information, make decisions, and generate personalized responses.

Architecture:

User Query
    ↓
Planner Agent
    ↓
Specialized Agents
    ↓
Final Response

Example Query:

"Find a gaming laptop under ₹80,000 with RTX graphics and good battery life."

====================================================

1. CUSTOMER AGENT
   ====================================================

File:
customer_agent.py

## Purpose:
Acts as the first AI agent in the workflow.
Responsible for understanding user intent and converting natural language into structured data.

## Input:
{
"query": "gaming laptop under 80000"
}

## Responsibilities:
1. Intent Detection
   * Understand what the customer wants.

2. Entity Extraction

   * Product category
   * Brand names
   * Specifications

3. Constraint Extraction

   * Budget
   * Color
   * Screen size
   * GPU requirements

4. Preference Identification

   * Battery life
   * Performance
   * Gaming
   * Portability

5. Query Structuring

   * Convert human language into machine-readable format.

## Output:

{
"budget": 80000,
"category": "laptop",
"gpu": "rtx",
"battery": true
}

## Technology:

LLM:

* Llama 3

Framework:

* LangGraph

State Management:

* LangGraph State

## Why Needed:

Without this agent every downstream service receives raw text.

This agent creates clean structured context for all other agents.

6. SHOPPING WORKFLOW
====================

File:
shopping_workflow.py

## Purpose:

Coordinates all agents using LangGraph.

## Workflow:

Customer Agent
↓
Recommendation Agent
↓
Pricing Agent
↓
Inventory Agent
↓
Marketing Agent
↓
Final Response

## Example Flow:

Step 1:
User asks for gaming laptop.

Step 2:
Customer Agent extracts requirements.

Step 3:
Recommendation Agent finds matching products.

Step 4:
Pricing Agent calculates discounts.

Step 5:
Inventory Agent verifies stock.

Step 6:
Marketing Agent generates offers.

Step 7:
System produces final recommendation.
